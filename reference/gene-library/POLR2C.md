# POLR2C: RNA polymerase II subunit C

A protein-coding gene on chromosome 16 (basal transcription machinery). Encodes the third largest subunit of RNA polymerase II, the polymerase responsible for synthesizing messenger RNA in eukaryotes. The product of this gene contains a cysteine rich region and exists as a heterodimer with another polymerase subunit, POLR2J.

**Corpus relevance:** Core RNA polymerase II machinery; general cellular function with no direct post-drug-syndrome link established.

**Protein (UniProt):** DNA-directed RNA polymerase II subunit RPB3 ([P19387](https://www.uniprot.org/uniprotkb/P19387/entry), reviewed)

**Function (UniProt):** Core component of RNA polymerase II (Pol II), a DNA-dependent RNA polymerase which synthesizes mRNA precursors and many functional non-coding RNAs using the four ribonucleoside triphosphates as substrates.

**Subcellular location (UniProt):** Nucleus.
